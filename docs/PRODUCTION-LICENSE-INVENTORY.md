## Privacy boundary

Public TRITON/Improvisator builders remove embedded HTML manuscript/history comments while preserving executable phrase attributions. Lucky's current builder uses the pinned original engine/app scripts and cloud CSS/art while excluding the trailing manuscript and development diary. The new About view replaces inherited blanket claims about ownership of rhythms. Preserved source prose is historical attribution and implementation material, not legal guidance or a separate rights grant. The private `reference/` and handoff directories are preserved locally and must not be copied wholesale into a public source archive. These are build boundaries, not guarantees about arbitrary user-imported HTML.

The existing authored code/compiled DSP descriptors contain author contact comments. Those are distinct from the user's private lyric/prompt library; they are inherited attribution, not secrets or an API credential. Review the contact convention if distributing the full source repository.
